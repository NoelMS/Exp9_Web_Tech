# Ex. 9 - Working with MongoDB using Shell Commands

Web Technology Lab (23CS2049).

mongosh commands for CollegeDB (CRUD, operators, sort, limit, count) and solutions to the sample questions, with the recorded sessions.

**Run:** Paste `sample-commands.js` into `mongosh` line by line. `session-*.txt` hold the output of a real run.

Live page: https://noelms.github.io/Exp9_Web_Tech/

The page shows the source and output captured from a real local run; this exercise needs a local server or MongoDB, so it cannot run on GitHub Pages itself.
